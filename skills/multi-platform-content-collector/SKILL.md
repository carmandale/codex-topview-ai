# Multi-platform Content Collector

Collect the data the user actually needs: content, accounts, comments, links, metrics, prompts, examples, competitor material, trend signals, or product feedback. Convert the request into explicit fields, then search, filter, verify, organize, and deliver the results across the requested platforms.

**File Path**: This skill is part of the TopView AI plug-in and is located at `skills/multi-platform-content-collector/`. Before running the auxiliary script, point `SKILL_DIR` to this skill directory.

---

## Core Principles

1. **Let the request determine the fields**: Understand the user's decision or research goal before choosing fields; do not default to only `prompt`.
2. **Public sources first**: Only publicly accessible content is collected; platforms that require login must use the user's existing login status and do not require a password.
3. **Traceability**: Each piece of data must retain the source link, platform, author/source, publishing time or crawling time.
4. **Ask less, act quickly**: Start when the request is sufficiently clear. Use reasonable defaults for missing fields and state them briefly.
5. **No unlimited retries**: If too few candidates are found, refine the keywords once. If the result is still sparse, deliver the verified data and explain the limitation.

## Step 0: Analyze collection tasks

After receiving the user's request, first parse the 6 parameters and do not lock the task to AI video or prompt:

| Parameters | Default values ​​| Examples |
|---|---|---|
| Collection target | The central object in the user's request | `Sora tutorial comments` / `AI video creators` / `Xiaohongshu competitor posts` |
| Data fields | Automatically generated by target | Platform, author, link, title, metrics, summary, key findings |
| Keywords | Extracted from the request | `seedance 2.0` / `cross-border ecommerce voiceover` / `TopView AI` |
| Platform | Default YouTube + Reddit + Bilibili | Users can specify X, TikTok, Xiaohongshu, Weibo, etc. |
| Quantity | Default 20 items | `collect 50 items` / `find 10 accounts` |
| Output form | Default table/list | Markdown, CSV, JSONL, Feishu table |

Confirmation sentence template:

> I will collect `<target>` with fields `<field_list>` across `<platform_list>`, aiming for `<N>` verified items.

## Common collection scenarios

### 1. General content/link collection

Suitable for: looking for cases, materials, news, posts, videos, comments, and information sources.

Recommended fields:
`platform`, `title`, `author`, `date`, `metric`, `url`, `summary`, `why_relevant`

### 2. Competitive product/topic research

Suitable for: competing product videos, popular content, user feedback, title scripts, and selling point angles.

Recommended fields:
`platform`, `competitor`, `content_type`, `hook`, `topic`, `engagement`, `url`, `insight`

### 3. List of creators/accounts

Suitable for: looking for experts, channels, potential partners, and vertical authors.

Recommended fields:
`platform`, `creator`, `profile_url`, `niche`, `sample_content`, `metric`, `contact_hint`, `reason`

### 4. Comment/feedback collection

Suitable for: product pain points, user reviews, frequently asked questions, and negative feedback.

Recommended fields:
`platform`, `source`, `comment_or_quote`, `sentiment`, `pain_point`, `url`, `date`

### 5. AI works + prompt word collection (retain as default)

Suitable for: The user clearly wants "prompt / prompt word / seedance / kling / sora work prompt word".

Recommended fields:
`platform`, `author`, `date`, `likes`, `url`, `prompt`

This scenario uses `search_all.py --mode prompt`, and abides by the following: the prompt words must be recorded in the original text, and must not be rewritten, translated, or completed; content without public prompts will be skipped.

## Workflow

```powershell
# If the current directory is the plugin root directory:
$env:SKILL_DIR = "skills\multi-platform-content-collector"
```

### Step 1: Environmental inspection

```bash
opencli doctor
```

- YouTube / Reddit / Bilibili are usually available directly.
- X/TikTok/Xiaohongshu/Weibo are browser-driven platforms: they are only enabled if explicitly requested by the user and the login status is available.
- If the Browser Bridge is offline or the platform triggers anti-crawling, switch to the non-browser platform and tell the user the reason for the skip.

### Step 2: Search for candidates

The default for general collection is `--mode general`:

```bash
python "$env:SKILL_DIR\scripts\search_all.py" "<keyword>" `
  --mode general --target 20 --platforms youtube,reddit,bilibili
```

The prompt word collection default is `--mode prompt`:

```bash
python "$env:SKILL_DIR\scripts\search_all.py" "<keyword>" `
  --mode prompt --target 20 --platforms youtube,reddit,bilibili
```

Commonly used parameters:

| Parameters | Purpose |
|---|---|
| `--mode general` | Universal collection, no additional binding prompt search suffix |
| `--mode prompt` | AI work prompt word collection, add prompt/prompt word search suffix |
| `--target N` | Target number of items |
| `--platforms a,b,c` | Limited platform |
| `--skip-browser` | Skip browser-driven platforms such as X/TikTok |
| `--budget-only` | Only preview the calling budget, no actual search |
| `--output PATH` | Custom candidate JSONL path |

Candidates are written to `/tmp/candidates.jsonl` by default and are sorted by interaction index from high to low.

### Step 3: Verification and extraction

Read 5 candidates each time and judge whether they meet the user's goals one by one:

```bash
head -n 5 /tmp/candidates.jsonl
```

Validation rules:

- Meet the collection goal: retain and extract fields.
- Does not meet the goal: skip, do not collect to make up the number.
- Insufficient information but relevant direction: reserved, mark uncertain points in `summary` or `note`.
- Field cannot be retrieved: fill in `N/A`, don't make it up.

For details, please refer to:

- Platform search and details command: `docs/platforms.md`
- Screening judgment method: `docs/filtering.md`

Save verified data:

```bash
python "$env:SKILL_DIR\scripts\save_verified.py" --from-file /tmp/entry.json
```

`/tmp/entry.json` can be any field structure, for example:

```json
{
  "platform": "YouTube",
  "title": "Example title",
  "author": "Example creator",
  "date": "2026-05-07",
  "metric": "120K views",
  "url": "https://example.com",
  "summary": "Why is this relevant to user needs?",
  "insight": "Reusable discoveries"
}
```

The prompt word preset can also continue to use the old parameters:

```bash
python "$env:SKILL_DIR\scripts\save_verified.py" "<platform>" "<author>" "<date>" "<likes>" "<url>" "<prompt>"
```

### Step 4: Organize the output

Choose according to user requirements:

- Respond directly to Markdown tables/lists.
- Write to CSV/JSONL.
- Write to Feishu form: refer to `docs/feishu-write.md`.

Before writing in Feishu, convert JSONL into the column order required by the user:

```bash
python - <<'PY'
import json
rows = []
with open('/tmp/collector_verified.jsonl', encoding='utf-8') as f:
    for line in f:
        d = json.loads(line)
        rows.append([
            d.get('platform', 'N/A'),
            d.get('title') or d.get('author') or d.get('source', 'N/A'),
            d.get('metric') or d.get('likes') or d.get('views') or 'N/A',
            d.get('url', 'N/A'),
            d.get('summary') or d.get('insight') or d.get('prompt') or ''
        ])
with open('/tmp/rows.json', 'w', encoding='utf-8') as f:
    json.dump(rows, f, ensure_ascii=False)
PY
```

### Step 5: Delivery Instructions

Instructions on delivery:

- Actual collection number and platform distribution.
- Data fields and output locations.
- Reasons when the target quantity is not reached.
- The next step is screening, analysis or supplementary mining.

## Caps and safety

- A maximum of `max(8, target)` candidate batches can be read, with 5 entries in each batch.
- When there are not enough candidates, the keywords can be changed and rerun at most once.
- After `Tripped: [twitter]` or `Tripped: [tiktok]` appears on the Browser platform, do not run the same platform again immediately.
- Do not collect content that is private, circumvents permissions, requires a paywall, or is not authorized by the user.
- Do not guess data to make up fields; if unknown, write `N/A`.
