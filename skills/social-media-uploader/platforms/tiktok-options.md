# TikTok upload configuration items

After AI reads this file, it collects information from the user according to the "Implemented" section.

## CLI required parameters (must be collected)

| Parameters | Description | Collection method | Limitations |
|------|------|---------|------|
| `--video` | Video file path | Dialogue question | mp4/mov/avi/mkv/webm/flv/wmv/3gp |
| `--title` | Video title | Asked by dialogue, if user does not give it, extract from file name | No hard limit |
| `--description` | Video description | Dialogue question, reuse title if user does not provide one | ≤3900 characters |

## Implemented profile configuration items (you can ask the user)

### Visibility `tiktok.visibility`

- **Collection method**: AskQuestion (only when the user actively mentions it)
- **Default**: `"everyone"`
- **Use the default if the user doesn't mention it, don't ask proactively**

AskQuestion template:
```json
{
  "id": "tiktok_visibility",
  "prompt": "Who can view this video?",
  "options": [
    { "id": "everyone", "label": "Everyone (default)" },
    { "id": "friends", "label": "friends" },
    { "id": "only_me", "label": "only myself" }
  ]
}
```

Mapping: directly use option id as the value of `"visibility"`.

### Regular release `tiktok.schedule`

- **Collection method**: Ask in dialogue
- **Default**: `null` (for immediate release)
- **Use the default if the user doesn't mention it, don't ask proactively**
- **Format**: `"YYYY-MM-DD HH:MM"`, such as `"2026-04-08 10:00"`

### Comments allowed `tiktok.allow_comments`

- **Collection method**: AskQuestion (only when the user actively mentions it)
- **Default**: `true`
- **Use the default if the user doesn't mention it, don't ask proactively**

### Second creation allowed `tiktok.allow_reuse`

- **Collection method**: AskQuestion (only when the user actively mentions it)
- **Default**: `true`
- **Use the default if the user doesn't mention it, don't ask proactively**

### Content Disclosure `tiktok.disclose_content`

- **Collection method**: AskQuestion (only when the user actively mentions it)
- **Default**: `false`
- **Use the default if the user doesn't mention it, don't ask proactively**
- **Description**: After opening, inform the audience that this post promotes the brand/product/service

### AI generated tag `tiktok.ai_generated`

- **Collection method**: AskQuestion (only when the user actively mentions it)
- **Default**: `false`
- **Use the default if the user doesn't mention it, don't ask proactively**
- **Important**: If the video is generated by AI, it is recommended to turn on this flag to comply with platform specifications

AskQuestion template:
```json
{
  "id": "tiktok_ai_generated",
  "prompt": "Flag as AI-generated content?",
  "options": [
    { "id": "no", "label": "No (default)" },
    { "id": "yes", "label": "Yes, marked as AI generated" }
  ]
}
```

### High quality upload `tiktok.high_quality`

- **Collection method**: AskQuestion (only when the user actively mentions it)
- **Default**: `true`
- **Use the default if the user doesn't mention it, don't ask proactively**

## CLI optional parameters

| Parameters | Description |
|------|------|
| `--cover` | Customize the cover image path (jpg/png), if not uploaded, it will be automatically intercepted by the platform |
| `--no-publish` | Just fill in the form without posting |
| `--resume-from` | Resume from breakpoint |
| `--profile` | Configuration file path |

## Cover image (pass the --cover parameter, do not use profile)

- **Default**: Do not pass `--cover`, the platform will automatically capture a frame from the video as the cover
- **The user explicitly provided a cover image path** → add `--cover "path"` (supports jpg/png)
- **Do not proactively ask users**, follow the "default first, never ask" principle of SKILL.md Step 1.4

## Generated profile JSON example

When the user says "Upload to TikTok, mark it as AI generated, scheduled to post at 10 o'clock tomorrow":
```json
{
  "tiktok": {
    "ai_generated": true,
    "schedule": "2026-04-08 10:00"
  }
}
```

When the user says nothing (all defaults are used): do not pass `--profile`, and the code automatically uses default.json.
